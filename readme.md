🎨 Canvas 2D con Programación Orientada a Objetos (OOP)

Aplicación web desarrollada con HTML, CSS, Bootstrap y JavaScript que demuestra el uso de Canvas 2D junto con Programación Orientada a Objetos (OOP) para crear y renderizar objetos gráficos.

El proyecto muestra cómo crear objetos, dibujarlos en un canvas y generar múltiples instancias de manera dinámica.

🚀 Demo del proyecto

La aplicación muestra tres ejemplos diferentes de uso de Canvas:

1️⃣ Objeto 2D simple
Se crea un círculo usando una clase en JavaScript y se renderiza en el canvas.

2️⃣ Objeto con posición aleatoria
El círculo se genera en una posición aleatoria dentro del canvas.

3️⃣ Múltiples objetos
Se generan varios círculos con posiciones, tamaños y colores aleatorios.

Este proyecto utiliza conceptos fundamentales de programación:
